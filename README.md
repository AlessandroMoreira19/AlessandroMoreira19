## 🌟 Projetos em destaque

Sistema web full stack para agendamento de aulas fitness, com Node.js, Express, MongoDB Atlas e interface interativa.

### 📺 [FEI TV](https://github.com/AlessandroMoreira19/fei-tv)
Aplicação desktop em Java para explorar conteúdos multimídia, com interface Swing, arquitetura MVC e banco de dados PostgreSQL.
